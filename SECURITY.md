# Security Policy

Tracefolio handles personal career data and reads source repositories, so privacy bugs matter to us.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through [GitHub Security Advisories](https://github.com/Kutluhankurt/tracefolio/security/advisories/new). Include steps to reproduce and the impact. You can expect an initial response within a week.

## In scope

- Secrets, sensitive file names or private repository details leaking into stored events or generated output
- Unapproved, unpublished or unverified data appearing in a resume or portfolio
- HTML or script injection in generated pages
- Path traversal in `tracefolio portfolio dev`

## Supported versions

Only the latest release receives fixes.
